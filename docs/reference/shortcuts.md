# Keyboard shortcuts

These are the default macOS keys. **Settings → Shortcuts** shows your current keys and changes them.
Every command is also in **⌘K**, with its key beside it.

## Folders and files

| Action                                     | Key                                          |
| ------------------------------------------ | -------------------------------------------- |
| Open a folder                              | **⌘⇧O**                                      |
| New folder plane                           | **⌘N**                                       |
| Go to a folder by path                     | **⌘L** or **⌘⇧G**                            |
| Open the selection                         | **⌘O** or **⌘↓**                             |
| Parent folder                              | **⌘↑**                                       |
| Back / forward                             | **⌘[** / **⌘]**; **⌥←** / **⌥→** in a folder |
| Quick Preview                              | **Space**                                    |
| Rename                                     | **Return**                                   |
| Get Info                                   | **⌘I**                                       |
| Copy / cut / paste                         | **⌘C** / **⌘X** / **⌘V**                     |
| Move copied items here                     | **⌥⌘V**                                      |
| Copy the full path                         | **⌥⌘C**                                      |
| Select all                                 | **⌘A**                                       |
| Select / deselect by pattern               | **⌃⌘=** / **⌃⌘-**                            |
| Duplicate                                  | **⌘D**                                       |
| Move to Trash                              | **⌘⌫**                                       |
| New folder / new folder with the selection | **⌘⇧N** / **⌃⌘N**                            |
| Show or hide hidden files                  | **⌘⇧.**                                      |
| Undo / redo a file change                  | **⌘Z** / **⇧⌘Z**                             |
| Copy / move to the paired folder           | **⌃⌘C** / **⌃⌘X**                            |
| Find files                                 | **⌘F**                                       |

## Commands and speech

| Action                        | Key              |
| ----------------------------- | ---------------- |
| Commands                      | **⌘K**           |
| Settings                      | **⌘,**           |
| Quit Viewer                   | **⌘Q** twice     |
| Dictate an Ask Viewer request | Hold **⌃⇧Space** |
| Key prefix                    | **⌃B**           |

The first **⌘Q** shows "Press ⌘Q again to quit"; press it again within 2.5 seconds, or hold it.
**Quit Viewer** in the menu, the Dock and logging out quit at once. To quit on the first press, turn
off **Settings → Browsing → Warn before quitting with ⌘Q**.

After the prefix, **?** shows what each key does and **:** opens the command line. Arrow keys and
range selection follow the active view. A terminal or text editor keeps its own keys.
[The command language](command-line.md) covers modes, aliases and macros.
