# Keyboard shortcuts

These are the default macOS bindings. Settings → Shortcuts shows current bindings and lets you
customize them. Commands remain searchable with **⌘K**.

| Action                                | Shortcut      |
| ------------------------------------- | ------------- |
| New folder plane                      | ⌘N            |
| Open folder / create folder           | ⌘⇧O / ⌘⇧N     |
| Open selection / rename               | ⌘O / Return   |
| Copy / cut / paste                    | ⌘C / ⌘X / ⌘V  |
| Select all                            | ⌘A            |
| Copy file or folder path              | ⌥⌘C           |
| Quick Preview / Get Info              | Space / ⌘I    |
| Commands / Settings                   | ⌘K / ⌘,       |
| Find file / go to folder              | ⌘F / ⌘L       |
| Parent folder                         | ⌘↑            |
| Back / forward                        | ⌥← / ⌥→       |
| Show hidden files                     | ⌘⇧.           |
| Duplicate / Move to Trash             | ⌘D / ⌘⌫       |
| Frame all / dock or reveal            | ⌘0 / ⌘Return  |
| New scratch / edit text               | ⌘T / ⌘E       |
| Save / Save As                        | ⌘S / ⇧⌘S      |
| Show or hide window navigation        | ⌥⌘S           |
| List / Grid / Columns / Gallery / Map | ⌘1 through ⌘5 |

Arrow and range-selection keys follow the active view. A terminal or text editor keeps its own
input; app shortcuts and configurable prefix behavior are separate. The default prefix is
**Ctrl+B**. Prefix `?` explains its bindings, and `:` opens the command line. See
[the command language](command-line.md) for modes, aliases and macros.
