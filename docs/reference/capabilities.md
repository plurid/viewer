# Features and where to find them

Everything Viewer does today, by area, with the key, the **⌘K** command and the menu that reach each
feature. Follow a feature's guide to learn it; open its reference for exact limits.
[The words Viewer uses](terms.md) defines the terms. Proposed features are not here; they are in
[research](../research/README.md).

## How to read the tables

- **Key** is the default macOS key. **Settings → Shortcuts** changes it. _Prefix_ **x** means press
  **⌃B**, then **x**.
- **⌘K command** is the label to type in **⌘K**, then its command id. The
  [command language](command-line.md) runs the id as a line (`:frame-all`); the [CLI](cli.md) and
  [agents](agents.md) name commands by the same id. `<…>` stands for a part that varies.
- **Menu** is the menu bar path, or **Right-click →** and the submenu of the file menu.
- A command appears only where it applies. A condition in the row, such as _PDFs selected_, says
  when. Typed in **⌘K**, a command that says why it does not apply here is listed greyed out under
  the others, with its reason: "laser" shows **Check laser job…** with "fabrication holds Job 1042
  and Evaluation: select one to check it." It does not run from there.

Right-click a file, a folder or empty space in a folder for the file menu. It starts with **Recent**
and **Suggested**, then the common actions, such as **Open**, **Quick preview**, **Rename…**,
**Copy**, **Copy path**, **Get info…** and **Move to Trash…**. Every other command that applies sits
in a submenu named for its group: **More file actions**, **View**, **Folder**, **Navigation**,
**Terminal**, **Git**, **Actions**, **Quick actions**, **Text**, **Preview**, **Lens**, **Plane**,
**Layout** and others. The actions button in a plane's header, such as **Folder actions** or
**Preview actions**, opens the same menu; in a preview plane, **Suggested** and the file tools act
on the plane's file. The menu's last row, and **Help → What Can I Do Here?**, lists every command
for the selection, says why one is unavailable, and pins up to eight to the plane's header.

Every setting is a command. An on/off setting reads **Turn on:** or **Turn off:** and its name, or
**Show …** and **Hide …**; a choice reads its name, a colon and the value; a number or colour reads
**Change …** and opens Settings at it. A setting the workspace cannot change itself, such as Trash
confirmation, opens Settings too. The Settings window has these pages: **Browsing**, **Navigation**,
**Previews**, **Editor**, **Space**, **Themes**, **Search**, **Permissions**, **Actions**,
**Models**, **Speech**, **Agents**, **Shortcuts**, **Terminals**, **Configuration** and **Privacy**.
