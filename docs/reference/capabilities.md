# Features and where to find them

Everything Viewer does today, by area, with the key, the **⌘K** command and the menu that reach each
feature. Follow a feature's guide to learn it; open its reference for exact limits.
[The words Viewer uses](terms.md) defines the terms. Proposed features are not here; they are in
[research](../research/README.md).

## How to read the tables

- **Key** is the default macOS key. **Settings → Shortcuts** changes it. _Prefix_ **x** means press
  **⌃B**, then **x**.
- **⌘K command** is the label to type in **⌘K**, then its command id. The
  [command language](command-line.md) runs the id as a line (`:frame-all`); the [CLI](cli.md) and
  [agents](agents.md) name commands by the same id. `<…>` stands for a part that varies.
- **Menu** is the menu bar path, or **Right-click →** and the submenu of the file menu.
- A command appears only where it applies. A condition in the row, such as _PDFs selected_, says
  when. Typed in **⌘K**, a command that says why it does not apply here is listed grayed out under
  the others, with its reason: "laser" shows **Check Laser Job…** with "fabrication holds Job 1042
  and Evaluation: select one to check it." It does not run from there.

Right-click a file, a folder or empty space in a folder for the file menu. It starts with **Recent**
and **Suggested**, then the common actions, such as **Open**, **Quick Preview**, **Rename…**,
**Copy**, **Copy Path**, **Get Info…** and **Move to Trash…**. Every other command that applies sits
in a submenu named for its group: **More file actions**, **View**, **Folder**, **Navigation**,
**Terminal**, **Git**, **Actions**, **Quick actions**, **Text**, **Preview**, **Lens**, **Plane**,
**Layout** and others. The actions button in a plane's header, such as **Folder actions** or
**Preview actions**, opens the same menu; in a preview plane, **Suggested** and the file tools act
on the plane's file. The menu's last row, and **Help → What Can I Do Here?**, lists every command
for the selection, says why one is unavailable, and pins up to eight to the plane's header.

## Files and views

### Open and move around

**Go to Folder…** opens with the current folder path selected, or Home without a folder. Untouched
or empty, it suggests up to eight remembered folders by visit count and age of last visit. Fragments
match names and paths, including near misses. Match quality comes before visit score, with the
folder's own name preferred to its parents. A name fragment activates the first suggestion;
**Return** opens the active row. **↑** and **↓** choose another row. A typed path starting with `/`,
`~`, `./` or `../` wins without an arrowed choice; an unavailable typed path shows an error.
Dot-prefixed names and fragments containing slashes can search history. Submitting a fragment before
results arrive waits for checking and opens the top result when checking ends. Visit updates
preserve the shown rows and active choice.

**⌘K** appends habit matches below existing rows: at most four with other results, eight alone.
Favorites and recent folders retain their command ranking; an open plane or Places row excludes its
duplicate habit row, including a checked link and its target. Inside a command folder, only that
folder's commands appear. `z` followed by a fragment immediately lists up to ten previously checked
folders. Other matches appear after checking. Its words match literally, in order through the path,
with the last word in the folder's own name. Late results append below rows already shown in the
palette, command line and **Ask in words**. A new query starts with its own ranking.

Viewer keeps at most 500 visit records beside the last 50 recents. The sidebar still shows the
latest eight recents. A deliberate folder open counts; session restoration, new-workspace Home,
templates, Back/Forward and Columns selection do not. A new visit stays when the record bound is
reached. Successful history checks use the filesystem's native canonical path for records, including
links into their targets. Recording and background checks after launch apply this same rule.
Navigation retains the chosen path. Case aliases merge on case-insensitive volumes; distinct
case-sensitive folders stay separate. Confirmed file entries are dropped. Failed or timed-out
checks, dangling links and unavailable volumes retain their records and spelling until a later
successful check.

Suggestions scan at most 500 records, making at most 40 metadata checks, two active at a time, with
150 ms for each read. Waiting for a lane does not consume that deadline or quarantine a volume.
Launch checks run in the background and send checked folders to every open window. All windows and
launch share two active lanes and at most six outstanding reads in dedicated threads, including
abandoned reads. Four abandoned reads leave both active lanes available. These synchronous worker
reads consume none of libuv's default four filesystem threads. In the App Store edition, history
uses only already-active folder access; it never starts or stops a permission grant. Remembered
folders without active access are listed unchecked, ranked as usual, and checked through ordinary
navigation when opened. Previously checked missing folders stay hidden. An unavailable volume is
checked once per query. Only a read that itself times out skips its identified volume for 30
seconds; queued reads do not block a healthy volume on later queries. Incomplete checks are reported
separately from an empty history.

**Go to Folder…** suggestions keep rank order. Lower-ranked results wait up to 150 ms for
higher-ranked checks; later results keep their rank without stealing the active choice. Renames
update shown paths. **Clear Recent Folders** in the palette, dialog or Recent section clears both
lists and removes their checked entries, including older saves arriving from another window. Forget
removes only that folder's checked entries. Unrelated checked folders remain ready for `z`. **Undo
clear recent folders** restores the cleared history from an offer in the clearing window for eight
seconds. Dismissal, quitting or a later Clear in any window ends the offer and releases its saved
paths. Undo applies folder renames received since the clear. Counts follow recents through local
saves, personal backups and folder renames. They are excluded from settings exports and are not
exposed to agents.

Ghostscript and its version. The button is absent in the Store edition. See
[reading documents](../guides/previews.md#read-postscript-eps-and-illustrator-files) and the
[format limits](formats.md).

Every setting is a command. An on/off setting reads **Turn On:** or **Turn Off:** and its name, or
**Show …** and **Hide …**; a choice reads its name, a colon and the value; a number or color reads
**Change …** and opens Settings at it. A setting the workspace cannot change itself, such as Trash
confirmation, opens Settings too. The Settings window has these pages: **Browsing**, **Navigation**,
**Previews**, **Editor**, **Space**, **Themes**, **Search**, **Permissions**, **Actions**,
**Models**, **Speech**, **Agents**, **Shortcuts**, **Terminals**, **Configuration** and **Privacy**.
Configured direct builds also have **License**. During the 30-day trial only About and this page
show days left. Afterward a hideable bar appears and every feature keeps working. The Store edition
and unconfigured builds have no license UI or record. Third-party notices remain in
**Acknowledgments**.
