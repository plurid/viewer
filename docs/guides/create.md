# Make a quick change

Select a file, press **⌘K** and type what you want: _convert_, _optimize_, _trim_, _PDF_. Every tool
writes new files and leaves the originals as they were, so you can compare before and after.

## Convert, crop or resize images

1. Select one or more images, press **⌘K** and choose **Convert images…**. In an image's preview,
   **Image tools…** opens the same tools.
2. Pick the **Format** (JPEG, PNG, WebP or AVIF) and the **Quality**.
3. Set **Width** and **Height** to resize; the aspect ratio is kept unless you change **Resize**.
4. Choose **Crop** to drag a crop, and **Rotate** to turn the picture.
5. Under **Metadata**, choose whether to keep or remove location and camera details.
6. Check the **Filename** and **Save in** folder, then choose **Export image**.

![Image tools converting a photograph to WebP](../media/create.png)

For a quick web copy, choose **Images for web…** instead: WebP, quality 80, at most 2048 pixels, GPS
removed. **Batch convert images…** applies one setting to a whole selection.

## Make files smaller

1. Select PDFs or images and choose **Optimize…**.
2. Pick **Balanced** for high quality, **Smaller** for stronger compression, or **Lossless** to keep
   every pixel, then choose **Prepare candidates**.
3. Read the results: each file shows its original size, its new size and the saving.
4. Untick any file you want to leave alone, choose the folder for the copies, and choose **Save
   smaller copies**.

![Optimize results comparing original and new sizes](../media/optimize.png)

A file marked **Already compact** could not get smaller, so Viewer keeps the original. **PDF for
email…** makes smaller copies of scanned PDFs for attaching to a message.

## Trim or join audio and video

1. Select a clip, or several, and choose **Edit media…**.
2. Play the clip and set **In** and **Out** to mark the part you want. Add more segments with **Add
   media…** and put them in order with each segment's up and down buttons.
3. To add music or a voice-over, choose **Add audio…**, pick the file, then choose **Replace audio**
   or **Mix with original** and set its start and volume.
4. Choose **Export sequence** for one file, **Export segments** for one file per segment, or
   **Export frame** for a still image.

Cuts are exact by default. The fast option cuts at the nearest keyframe, which is quicker but less
precise.

## Rearrange a PDF

1. Select one or more PDFs and choose **PDF tools…**.
2. Drag pages into order, rotate them, or remove the ones you do not need. Pages from several PDFs
   can go into one.
3. Check the page plan, choose the destination and export.

**Create PDF from images** turns a selection of images into one PDF. To put several photos or pages
on one sheet, [lay them out](layout.md). [PDF tools](../reference/pdf.md) lists what protected and
signed PDFs allow.

## Write something down

| To                                 | Choose in **⌘K**               |
| ---------------------------------- | ------------------------------ |
| Keep notes that save as you type   | **New note plane**             |
| Keep a checklist                   | **New checklist plane**        |
| Write text you will save as a file | **New scratch plane** (**⌘T**) |
| Find a note or checklist again     | **Notes…**                     |

Closing a note's plane keeps the note. To remove it, use **Move to Trash** in the note itself.

[Media reference](../reference/media.md) has the formats and limits for every export.
