# Your first five minutes

Start here once Viewer is installed. Five short steps show you how to open a folder, look inside a
file, find files, keep a file open beside its folder and find any action. If Viewer is not installed
yet, follow [Install and update Viewer](install.md).

**Find it:** **Help → Getting Started** opens this page; **Help → Keyboard Shortcuts** lists every
key.

The first time Viewer opens, a card above the folder's files names three things to try: **Space**,
**⌘K** and dragging a plane by its title. **Space** and **⌘K** each leave the card once used, and
once both have, the card goes for good. Its **×** closes it for good too.

## 1. Open a folder

1. Press **⌘⇧O**, or choose **File → Open Folder…**, and pick a folder. The sidebar also opens Home,
   Desktop, Documents, Downloads, Pictures, Applications and the Trash.
2. Double-click a folder to enter it. **⌘↑** goes to the parent folder; **⌘[** and **⌘]** go back
   and forward.
3. Change the view with **⌘1** List, **⌘2** Grid, **⌘3** Columns, **⌘4** Gallery or **⌘5** Map, or
   use the **View mode** button in the folder's header. Each folder keeps the view you chose for it.

The folder opens in a [plane](../reference/terms.md#planes-and-the-space): every open view in
Viewer, whether a folder, a file, a note or a terminal, is a plane.

## 2. Look inside a file

1. Select a file and press **Space**. Try a photograph, a PDF, a Word document or a video.
2. With several files selected, press **←** and **→** to step through them.
3. Press **Space** or **Escape** to close the preview.

This look is [Quick Preview](../reference/terms.md#looking-at-files). Its footer opens the file in
its own app, edits a text file with **Edit** (**⌘E**) and offers the next step that fits it.

In Columns view, the selected file's preview sits beside the folder trail, so you can browse and
read at the same time.

![Columns view with a PDF preview beside the folder trail](../media/columns.png)

[Read and inspect files](previews.md) covers each kind of file's controls.

## 3. Find something

1. Press **⌘F** and type part of a filename. Matches in the folder appear as you type; choose one to
   open it.
2. To look below the folder too, choose **This folder** beside the results and change it to
   **Subfolders**. **Indexed locations** searches everything Viewer has indexed.
3. Narrow the results with a filter: `ext:pdf` shows PDFs, `kind:folder` shows folders, `size>10mb`
   shows large files.
4. To find words inside documents, turn on **Document text**. It searches the locations whose
   **Contents** box is on in **Settings → Search**.

[Search](../reference/search.md) lists every filter.

## 4. Keep a file open beside its folder

1. In Quick Preview, choose **Open linked plane**. The file opens in its own plane, linked to the
   folder it came from: a [linked plane](../reference/terms.md#planes-and-the-space).
2. Press **⌘0** to bring every plane into view.
3. Press **⌘Return**, or choose **Dock plane** in a plane's header, to give one plane the whole
   window. Press it again to see all of them.
4. Close a plane with **×** in its header, or **⌥⌘W**. Closing a plane never touches the file.

## 5. Find any action

Press **⌘K** and type what you want to do: _rename_, _convert_, _optimize_, _note_, _terminal_. The
list offers what fits the current folder and selection, with each shortcut beside it.

![The command palette offering image actions for a selected photograph](../media/palette.png)

Right-click a file for the same actions. **Suggested** at the top of that menu offers the next step
for what you selected. **Help → What Can I Do Here?** lists everything available for the selection,
and lets you pin the ones you use most to the plane's header.
