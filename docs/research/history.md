# The earlier Viewer

The maintained application is the Electron desktop app described in
[the development guide](../development/README.md). An earlier 2021 Viewer used a different
application architecture; its source is retained in Git history at commit `bd198da`.

That predecessor is background for product research, not an alternative current setup. Features,
dependencies and file layouts described in its old documents must be rechecked before reusing an
idea. Existing legacy application data is not automatically imported or rewritten by the current
app.

For current capabilities, use [the reference](../reference/capabilities.md).
